3. GETTERS E SETTERS
====================
No Eclipse:
Source → Generate Getters and Setters → Select All → Generate

Formato:
public int getCodigo() {
    return codigo;
}

public void setCodigo(int codigo) {
    this.codigo = codigo;
}

Lembre:
this = atributo da classe
codigo = parâmetro

7. CÁLCULOS IMPORTANTES
=======================
double media = (nota1 + nota2) / 2;
double total = preco * quantidade;
saldo += valor;
saldo -= valor;
quantidade += valor;
quantidade -= valor;

CUIDADO:
nota1 + nota2 / 2  ← ERRADO para média
(nota1 + nota2) / 2 ← CERTO


8. VOID X RETURN
================
void = executa uma ação

public void consultarSaldo() {
    System.out.println(saldo);
}

return = devolve um valor

public double calcularMedia() {
    return (nota1 + nota2) / 2;
}


9. PRINTLN X PRINTF
===================
System.out.println("Nome: " + nome);

System.out.printf("Média: %.2f%n", media);
System.out.printf("Preço: R$ %.2f%n", preco);

%.2f = 2 casas decimais
%n = quebra de linha


10. CONSTRUTOR
==============
public Classe(int codigo, String nome) {
    this.codigo = codigo;
    this.nome = nome;
}

Uso:
Classe objeto = new Classe(101, "Teste");

Se não houver construtor personalizado:
Classe objeto = new Classe();


11. SCANNER

import java.util.Scanner;

Scanner scanner = new Scanner(System.in);

double preco = scanner.nextDouble();

12. MENU — DO WHILE + SWITCH
============================
int opcao;

do {

    System.out.println("1 - ...");
    System.out.println("2 - ...");
    System.out.println("0 - Sair");
    opcao = scanner.nextInt();

    switch (opcao) {

        case 1:
            // ação
            break;

        case 2:
            // ação
            break;

        case 0:
            System.out.println("Saindo...");
            break;

        default:
            System.out.println("Opção inválida.");
            break;
    }

} while (opcao != 0);

CONTA CORRENTE
--------------
private int numero;
private String titular;
private double saldo;

public void depositar(double valor) {
    saldo += valor;
}

public void sacar(double valor) {
    if (valor <= saldo) {
        saldo -= valor;
    }
    else {
        System.out.println("Saldo insuficiente.");
    }
}

public void consultarSaldo() {
    System.out.printf("Saldo: R$ %.2f%n", saldo);
}


PRODUTO
-------
private int codigo;
private String nome;
private double preco;
private int quantidade;

public void adicionarEstoque(int quantidade) {
    this.quantidade += quantidade;
}

public void removerEstoque(int quantidade) {
    if (quantidade <= this.quantidade) {
        this.quantidade -= quantidade;
    }
    else {
        System.out.println("Estoque insuficiente.");
    }
}

public double calcularValorEstoque() {
    return preco * quantidade;
}

15. ERROS MAIS PROVÁVEIS
========================
- esquecer private
- esquecer getter/setter
- usar This em vez de this
- variável não declarada
- média sem parênteses
- esquecer ;
- esquecer }
- esquecer break
- esquecer nextLine() do buffer
- colocar regra no Main em vez da classe
- texto de saída errado

=================
